# エンジニア キャリアプランシート

メイテック横浜西EC のエンジニア向けキャリアプランシート。IT分野 v1.1。

エンジニアが自分の現在地を言語化できるようにするための自己評価シート。
人事評価や要員アサイン判断には使わない。総合評価、等級、適合度％、順位は出力しない。

## 読む順序

1. `docs/01_要求仕様書.md` — 何を求められ、どう扱ったか
2. `docs/02_仕様書.md` — 何を作るか
3. `docs/03_エビデンス編.md` — 順位を出さない判断の根拠

## ディレクトリ

```
CLAUDE.md              作業ルールと確定した設計判断
docs/
  01_要求仕様書.md     要求の一元管理（REQ-nnn）
  02_仕様書.md         設問・分析・データ・画面の仕様
  03_エビデンス編.md   フィードバック研究の調査結果
  90_執筆基準.md       文書の書き方
  minutes/             打合せ議事録と対応状況
prototype/
  sample_v1.html       動作サンプル
  legacy_r1.html       作り直し前のシート
.claude/skills/
  requirement-triage/  要求の起票
  spec-update/         仕様への反映
  doc-consistency/     整合性の検査
```

## プロトタイプの実行

`prototype/sample_v1.html` をブラウザで開く。Chart.js を CDN から読むため、ネットワーク接続が必要。
