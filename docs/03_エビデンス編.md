# キャリアプランシート エビデンス編

## 1. この資料について

設計書で「総合評価・等級・職種の適合度％・順位を出さない」と決めた根拠をまとめる。
設計書本体からは分離し、この判断に説明が必要な場面で参照する。

## 2. 結論

自己評価と育成を目的とするシートに、順位や等級を出力してはならない。理由は3つ。

1. 数値評点と記述を併記すると、記述の効果が消える
2. フィードバックは平均すると有効だが、注意が課題から自己へ移ると成績を下げる。順位提示はこれに該当する
3. 主要企業は同じ理由で順位評価を撤廃している。ただし揺り戻しもあり、論点は処遇と連動しているかで分かれる（5章）

関連職種を挙げること自体は問題ない。害があるのは数値化と順位付けであり、質的な情報ではない。

順位を出さない代わりに、判断の基準はアンカーが与える。これが自己評価の精度を担保する仕組みになる。

## 3. 根拠

### 3.1. 評点は記述を打ち消す

Butler (1988) は、数値評点だけを与えた群、記述コメントだけを与えた群、両方を併記した群を比較した。
興味と成績が向上したのは記述のみの群だけで、併記した群は評点のみの群と同じ結果になった。

評点は他者との比較に注意を向け、記述は習熟そのものに注意を向ける。前者が働くと後者は消える。

本件への含意は、併記が妥協案として成立しないことである。
守備範囲マップやレーダーに総合評価を併記すると、総合評価だけを出したのと同じ結果になる。

### 3.2. フィードバックの3分の1以上は成績を下げる

Kluger & DeNisi (1996) は131実験のメタ分析で、フィードバックの平均効果は正（d = 0.41）だが、
38%の実験で成績が低下したことを示した。低下の条件は、注意が「課題」から「自己」へ移ることである。

順位・等級・％は注意を自己に向ける。「自分は何ができて何ができないか」ではなく「自分はBだ」に向く。
理論上、成績を下げる側の条件に該当する。

### 3.3. 教育場面の知見はキャリアにも当てはまる

両研究とも対象は児童や課題遂行であり、キャリア支援の場面ではない。
しかし働いている仕組みは同じで、「評価される自分」に注意が向くと「何を伸ばすか」への関心が失われる。
動機づけのこの構造は年齢や場面に依存しない。

むしろ自己評価のほうが害は出やすい。
人事評価には処遇という外的動機が伴うが、自己評価にはそれがなく、内発的動機だけで動いているためである。

## 4. 実務での撤廃事例

| 企業 | 時期 | 内容 |
| --- | --- | --- |
| Adobe | 2012 | 評価スコアを廃止し Check-in へ。評価通知後に、残ってほしい人材が離職していた |
| Microsoft | 2013年11月 | スタックランキングを廃止 |
| Deloitte / GE / Accenture | 2014〜2015 | 従来型の年次評価を廃止し、頻度の高い対話へ移行 |

Deloitte の Global Human Capital Trends 2015 では、評価制度を再設計した企業の90%がエンゲージメントの改善を報告している。
W. Edwards Deming は40年以上前から、人事考課そのものが動機を損なうとして廃止を主張していた。

## 5. 反証と限界

結論に反する証拠もある。片側だけで判断していない。

### 5.1. 評価廃止には揺り戻しがある

評価を廃止した企業で、従業員のパフォーマンスが約10%低下したという調査がある。
あわせて、マネージャーとの対話の質が低下し、高業績者が報酬決定に不満を持ちやすくなり、エンゲージメントスコアも下がったと報告されている。
4章の事例は、この揺り戻しが表面化する前の時点のものである。

本件への適用は以下のとおり。

- 10%の低下は処遇と連動した人事評価の話である。本シートは報酬にも等級にも紐づかない
- ただし「対話の質が下がる」部分は転移する。具体的な材料がないと面談が空疎になるため
- 本設計では守備範囲マップと観点別レーダーがその材料になる

### 5.2. 自己評価は基準がないと精度が出ない

55研究のレビューで、自己評価と客観指標の相関は平均0.29だった。
較正の研究では、規範的な基準を与えると較正の失敗率が有意に下がる一方、自己知識だけを与えても下がらない。

順位も比較も総合スコアも出さない設計は、自己評価の精度が最も出にくい条件に当たる。

本件への適用は以下のとおり。

- アンカーがこの規範的基準に相当する。各段が何を意味するかを外部から定義している
- したがって規範を与えつつ順位は与えない、という中間解になる
- アンカーは表記統一のための道具ではなく、精度を担保する主要な仕組みである

### 5.3. Kluger & DeNisi の主結果は「平均して有効」

d = 0.41 は正の値であり、フィードバックは平均すると成績を上げる。38%はその裏面であって主結果ではない。
この研究はフィードバック自体を否定する根拠にはならない。

本件への適用は以下のとおり。

- 本設計はフィードバックを減らしていない。観点を約45から88に増やし、粒度を上げている
- 減らしたのは順位と総合スコアだけである

## 6. 設計への反映

| 項目 | 判断 |
| --- | --- |
| 総合評価（A / B / C など） | 出さない |
| 職種の適合度％ | 出さない |
| 職種ランキング（TOP3 など） | 出さない |
| 関連職種の列挙 | 出す。順位・％は付けない |
| 強み・弱み | 出す。該当する観点名を列挙し、順位・点数は付けない |
| 守備範囲マップ、レーダー | 出す。これらが主出力 |
| アンカー | 順位の代わりに判断基準を与える。自己評価の精度を担保する主要な仕組み |
