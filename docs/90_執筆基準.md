# 執筆基準

キャリアプランシート関連文書（設計書、エビデンス編、v2以降の各分野版）に共通で適用する。
成果物には含めない。編集時の参照用。

## 記述

| 対象 | 基準 |
| --- | --- |
| 節の冒頭 | その節が何を定めるかを1〜2文。それ以上の前置きは書かない |
| 決定事項 | 断定形で書く。決まったことだけを書く |
| 未決事項 | 仕様書には書かない。要求仕様書の該当 REQ に置く。「未定」「暫定」「検討中」を仕様書に残さない |
| 要求への参照 | 仕様書に REQ 番号を書かない。要求の進行状態であって仕様ではない |
| 課題 | 仕様書には書かない。仕様書は、そう設計したという事実を書く場所である |
| 理由 | 「なぜそうしたか」が自明でない場合のみ1行。自明なことは書かない |
| 経緯 | 書かない。「以前はこうだったが変えた」は編集履歴であって仕様ではない |
| 用語 | 設計書1章の定義表にあるものだけ使う。比喩・造語は使わない |

## 形式

| 対象 | 基準 |
| --- | --- |
| 表のカラム名 | 一般語のみ。この文書固有の言い回しをカラム名にしない |
| 一覧の記法 | 観点・項目の列挙は番号付きリスト。スラッシュ区切りは使わない |
| 散文 | 3文以上続く説明は箇条書きにする |
| 参照 | 「6章 #3」の形式。節番号への参照は使わない |
| 強調 | 使わない。強調が必要なら文を分ける |

## 禁止表現

過去に読み手に伝わらなかった表現。使わない。

| 使わない | 代わりに |
| --- | --- |
| 持ち運べる力 / 持ち越せる | ジャンルを横断して使える力 |
| 軸 / 軸でないもの | 何で位置づけるか、を平易に書く |
| 展開（カラム名として） | 回答対象 |
| 設計意図（見出しとして） | 目的として節冒頭の箇条書きに含める |

## 編集手順

1. 既存ファイルは差分編集する。全体上書きはしない
2. 相手の編集が入っている可能性がある場合は、先に現状を読んでから編集する
