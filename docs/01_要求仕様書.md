# エンジニア キャリアプランシート 要求仕様書

## 1. この資料について

キャリアプランシートに対する要求を一元管理する。何を求められ、それをどう扱ったかを記録する。
仕様書（02_仕様書.md）が「何を作るか」を定めるのに対し、本書は「なぜそうなっているか」を保持する。

| 章 | 内容 |
| --- | --- |
| 2 | 記載ルール |
| 3 | 目的から導出した要求 |
| 4 | 打合せから起票した要求 |
| 5 | レビューから起票した要求 |
| 6 | 保留・見送りの一覧 |

## 2. 記載ルール

要求は REQ-nnn で識別する。番号は再利用しない。

| 項目 | 内容 |
| --- | --- |
| 出所 | 目的／議事録（日付）／レビュー |
| 実現性 | 可／条件付き可／不可 |
| 状態 | 反映済／保留／見送り |
| 反映先 | 仕様書の章番号。見送りの場合は理由を書いた章 |

状態が「反映済」であっても、仕様が確定したという意味ではない。仕様書8章の未確定事項は別に管理する。
